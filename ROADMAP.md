# World Smith - Development Roadmap

> 3D Open World MMORPG inspired by RYL2 combat and Ultima Online depth
>
> PRD: See [prd-world-smith.md](./prd-world-smith.md) for full design specification

---

## Vertical Slice Goal

A playable demo with basic combat, one region, one playable class, and working enemy AI.

Estimated: ~20-30 files/core systems to implement

---

## Phase 1: Core Combat Engine

Priority order - these must exist for anything else to work

**PRD References:** Section 3 Combat Systems, Section 3.3 Combat Actions, Section 3.6 Death & Resurrection

### 1.1 Projectile System [CRITICAL]
**Files:** `godot-project/core/combat/projectile.gd`

- [ ] Base Projectile class with position, velocity, lifetime
- [ ] Projectile collision detection (hitbox vs entities)
- [ ] Projectile expiration (max range, time, out of bounds)
- [ ] Explosion on impact for PROJECTILE_AOE skills
- [ ] Visual VFX integration (scene loading)
- [ ] Server authoritative spawning (multiplayer prep)

### 1.2 Interrupt System [CRITICAL]
**Files:** `godot-project/core/combat/combat_system.gd` (update)

- [ ] Track channeling/casting skills per entity
- [ ] Damage event triggers interrupt check
- [ ] immune_interrupt flag check
- [ ] Interrupted -> cancel cast, partial resource cost, maybe cooldown reset
- [ ] Visual/audio feedback for interrupt

### 1.3 Aggro and Threat System [CRITICAL]
**Files:** `godot-project/core/combat/aggro_system.gd`

- [ ] Threat values per entity (who is attacking whom)
- [ ] add_threat(entity, amount) - threat generated by damage/healing
- [ ] get_highest_threat(entity) - who enemy should attack
- [ ] Threat decay over time (out of combat)
- [ ] Threat transfer on target death

### 1.4 Enemy AI [CRITICAL]
**Files:** `godot-project/core/entities/enemy_ai.gd`, `godot-project/entities/enemies/enemy_controller.gd`

- [ ] Proximity aggro detection (configurable radius)
- [ ] AI states: IDLE, PATROL, CHASE, COMBAT, FLEE, RETURN
- [ ] Target selection (highest threat, closest, etc.)
- [ ] Basic attack behavior
- [ ] Use of skills based on cooldown/range
- [ ] Respawn behavior

### 1.5 Death and Respawn [CRITICAL]
**Files:** `godot-project/core/entities/entity.gd` (update), `godot-project/core/combat/respawn_handler.gd`

- [ ] Death state (no input, no damage)
- [ ] Corpse entity (visual, lootable)
- [ ] Respawn timer (configurable per zone)
- [ ] Respawn location selection (bind point, nearest, etc.)
- [ ] Stat/experience penalty on death (optional)

## Phase 2: Combat Foundation

Core combat mechanics that make the game feel right

**PRD References:** Section 3.4 Stats & Attributes, Section 3.5 Health & Resource Display

### 2.1 Global Cooldown (GCD)
**Files:** `godot-project/core/combat/combat_system.gd` (update)

- [ ] GCD duration (default 1.0s)
- [ ] Skills add to GCD (optional per skill)
- [ ] GCD prevents skill queue
- [ ] Client-side prediction with server validation

### 2.2 Combat State Tracking
**Files:** `godot-project/core/combat/combat_state.gd`

- [ ] in_combat flag per entity
- [ ] combat_start_time timestamp
- [ ] Out-of-combat timer (default 5-10s no damage)
- [ ] Mana regen rate changes (combat vs rest)
- [ ] UI integration (combat indicator)

### 2.3 Hit Calculation (Miss/Evade/Block/Dodge)
**Files:** `godot-project/core/combat/combat_math.gd` or `entity.gd` update

- [ ] Hit chance calculation
- [ ] Miss (random roll below hit chance)
- [ ] Evade (dodge stat roll)
- [ ] Block (shield/block stat roll)
- [ ] Partial damage on block
- [ ] Parry, Resist (magical) as variants

### 2.4 Dispel/Cleanse System
**Files:** `godot-project/core/combat/dispel_handler.gd`

- [ ] Effect categories (MAGIC, CURSE, POISON, PHYSICAL)
- [ ] can_dispel(category) check
- [ ] dispel_effect(category) removes matching effects
- [ ] Hard vs soft dispel (instant vs gradual)
- [ ] Priority rules for multiple dispels

### 2.5 Buff Stacking Rules
**Files:** `godot-project/core/entities/status_effect.gd` (update)

- [ ] Same buff: REPLACE, STACK, REFRESH duration
- [ ] Different buff same stat: HIGHEST wins, ADD, CUMULATIVE
- [ ] Buff icons/priority for UI
- [ ] Maximum buff/debuff counts
