# Community

Synmergia is built in the open. The player-facing world and the source tree are two doors into the same project.

## Play and read

| Place | What is there |
|---|---|
| [synmergia.creadev.org](https://synmergia.creadev.org/) | The main website |
| [Play](https://synmergia.creadev.org/play) | The browser client |
| [Codex](https://synmergia.creadev.org/codex) | Classes, skills, items, enemies, recipes, mounts, and more |
| [Lore](https://synmergia.creadev.org/lore) | The story and canon |
| [Rules](https://synmergia.creadev.org/rules) | How to play in good faith |
| [Open Source](https://synmergia.creadev.org/opensource) | Why the project is open and who it is for |

The player-facing wiki and Fandom live with the website, not in these docs. The Codex is generated from the game data; it is the canonical browse surface.

## How docs change

Docs are part of the repository. This portal deploys from `main`, so open a pull request against `main` for a page correction. Engine and data changes follow the usual `staging` flow in [CONTRIBUTING.md](https://github.com/dhaupin/synmergia/blob/main/CONTRIBUTING.md). Do not treat this portal as a wiki that can drift away from the code.

For a docs bug, include the page URL and the line that is wrong. For a code bug, include the version, the reproduction, and the expected result.
