# Synmergia Web Client

Cloudflare-hosted HTML5 client for the Synmergia MMORPG.
Built on Godot 4.7.2's HTML5 export with a custom shell.

## Directory Structure

```
web/
├── index.html          # Main page with canvas + Godot init
├── config.js           # Server URLs and engine options
├── style.css           # Loading screen, error screen, FPS counter
├── wrangler.toml       # Cloudflare Workers config
├── worker.js           # Cloudflare Worker (static + WebSocket proxy)
├── game.js             # Godot JS glue (generated by export)
├── game.wasm           # WASM binary (generated by export)
├── game.pck            # Packed resources (generated by export)
└── shared/
    ├── input.js        # Input handling (mouse, touch, keyboard)
    └── network.js      # WebSocket client for server comms
```

## Building

### Prerequisites
- Godot 4.7.2 with HTML5 export template installed
- Node.js (for wrangler)

### Steps

1. **Install Godot HTML5 export template** (if not already):
   ```bash
   godot --headless --export-template
   ```

2. **Export the game**:
   ```bash
   cd game
   godot --headless --export-html5 ../web
   ```

3. **Deploy to Cloudflare**:
   ```bash
   cd web
   npm install
   wrangler deploy
   ```

### Environment Variables

Set these in `wrangler.toml` or via `wrangler secret put`:

| Variable | Description | Default |
|----------|-------------|---------|
| `SERVER_URL` | WebSocket server URL | `wss://synmergia.example.com/ws` |
| `API_URL` | REST API URL | `https://api.synmergia.example.com` |
| `DEBUG` | Enable debug output | `false` |

## Architecture

- **Input**: Shared `Int32Array` buffer for mouse/touch/keyboard events
- **Network**: Binary WebSocket protocol (type byte + payload)
- **Rendering**: Godot WASM with HTML5 canvas
- **Hosting**: Cloudflare Workers with static asset caching

## Browser Support

- WebAssembly (all modern browsers)
- WebSocket (all modern browsers)
- Touch support (mobile Safari, Chrome)
- Minimum: Chrome 89+, Firefox 89+, Safari 14+, Edge 89+
