# Interiors + UI Mockups (Gemini brief pack)

> **Goal:** the remaining environment interiors (inn, dwelling,
> gateway chamber) plus the first UI skin mocks -- HUD, inventory
> icons, and the Aether-Conduit terminal chrome. Interiors obey the
> canon shop grammar from labs/art-direction.md sec. 8.4; UI obeys
> the semantic accent rule (sec. 3): teal = interactive/dormant,
> gold = reward/active, violet NEVER on buttons or chrome.
>
> **Canon anchors:** the four canonized shop interiors (vault,
> academy, blacksmith, storekeeper); Aether-Conduit = the in-world
> terminal term (sec. 8.3).
