# Trademark & Brand Policy

The Synmergia source code and assets are released under the
[MIT License](./LICENSE). That license grants you broad rights to use,
modify, and redistribute the **code and content**. It does **not** grant
any rights to the **Synmergia name or logo**.

This is the standard, intended split: an open source license covers
copyright, and trademark is a separate thing. It exists so that "open
source" does not mean "anyone can ship something confusingly called
Synmergia."

## What you may do

- Use, fork, modify, and redistribute the code under the MIT terms.
- Run your own server or build your own version of the game.
- Say your project is **based on** or **a fork of** Synmergia, with a
  link back to this repository.
- Use the name in factual, descriptive ways (e.g., "compatible with
  Synmergia", "built on the Synmergia engine").

## What you may not do

- Use the Synmergia name or logo as the name or branding of your own
  product, server, or fork in a way that suggests it is the official
  project or is endorsed by it.
- Use the name or logo in a way that implies affiliation you do not have.
- Register the Synmergia name (or a confusingly similar mark) as your own
  trademark, domain, or project name.

## Forks

If you fork the game, please give it your own name and branding so players
can tell the projects apart. Crediting the original is appreciated and
encouraged.

## Questions

Not sure whether a use is fine? Ask by opening an issue — we would rather
say yes than have you guess.
